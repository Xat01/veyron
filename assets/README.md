Palette (dark-interface compatible):

- Deep charcoal `#0f172a` — near-black page backgrounds
- Steel blue `#38bdf8` — primary accent (precision)
- Slate `#64748b` — muted text and borders
- Warn amber `#f59e0b` — medium findings
- Alert red `#ef4444` — critical/high findings
- Safe green `#22c55e` — validated/repaired states

Typography:

- Headings: system-ui bold, uppercase, tight letter-spacing
- Body: system-ui, 13–14 px, 1.5 line height, high contrast (#f1f5f9 on #0f172a)
- Code: Consolas / Menlo / monospace

Social preview rasterised to `assets/veyron-social-preview.png` at 1200 × 630 px for GitHub.

SVGs are self-contained, script-free, and embed no remote resources.
